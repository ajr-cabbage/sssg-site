## The Problem With The Internet
Social Media.

## The Real Problem With The Internet
It wasn't all that long ago, that you could make a free hosted website. Hand-write some HTML, upload some files, and you had something of your own out on the web. There was no requirement for it to generate engagement, no likes, subscribers, nor commenters. The only thing that mattered was that you enjoyed creating it.

There are very few places online this can happen and it is certainly not the default experience. The internet felt like magic when I was young and I want that for my children. It will never be the same as it was. I will spend considerable time teaching them how to protect themselves in an always-online world, but I can make a space for them to capture some of the magic.

## Why This Silly Project
### Make it manual, but easy.
Using the command line feels awesome but there's a barrier to entry. This is a simple introduction to making something tangible with a short feedback loop. The commands are simple and the results are visible immediately. There are no languages you need to learn to get started, just a little practice with markdown.
### Make it small and fast
It doesn't need to do much, so it shouldn't take very long to do it. Write, build, and serve.
### Make it shitty
The best website is the one you make yourself. Make it yours, even if it's ugly.
### Let it grow
The first website will be served on localhost on http. As you learn more, wire it up with https, serve it on the open web, get a domain, add features ... make it less shitty.
